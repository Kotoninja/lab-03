# Лабораторная работа 3. Каталог объектов

## Структура проекта

```text
.
├── src/
│   ├── __init__.py
│   ├── main.py                  # Точка входа
│   ├── catalog.py               # Операции с каталогом книг
│   ├── models.py                # Модель книги и проверка её полей
│   ├── repository.py            # Загрузка и сохранение каталога
│   ├── errors.py                # Исключения каталога
│   ├── mocks/                   # Примеры входных JSON-файлов
│   │   ├── v1.json
│   │   └── v2.json
│   └── results/                 # Сохранённые каталоги
│       └── save_1.json
├── scripts/
│   └── v1/
│       └── catalog_demo.py      # Демонстрационный сценарий
├── tests/
│   ├── __init__.py
│   └── test_models.py           # Тесты модели книги
├── Makefile                     # Команды запуска
├── pyproject.toml               # Настройки и зависимости проекта
├── requirements.txt            # Список зависимостей для pip
├── uv.lock                      # Зафиксированные версии зависимостей
├── .gitignore                   # Исключения для Git
├── .pre-commit-config.yaml      # Настройки pre-commit
└── README.md                     # Описание проекта
```
